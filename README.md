# TFAM Audio Guide

A mobile web app for visitors to the Taipei Fine Arts Museum. It lets
visitors browse what's on, see activities and book them, navigate a floor
map, and play audio guides for artworks. The app is bilingual (English /
Chinese) and designed mobile-first.

## Tech Stack
- **Next.js 16 (App Router)**
- **React 19**
- **TypeScript** (strict mode)
- **Tailwind CSS v4**
- **motion** (Framer Motion v12) — page transitions and animations
- **npm** — the only supported package manager (there is a package-lock.json)

## Commands
- Install:      `npm install`
- Dev server:   `npm run dev`      (opens at http://localhost:3000)
- Build:        `npm run build`    (this ALSO type-checks the whole project)
- Type-check:   `npx tsc --noEmit` (type-check without building)
- Start (prod): `npm start`
